# Activity Log — CareerUp (UAS Software Development Fundamentals)

Log ini mencatat pekerjaan tiap anggota. Isi sambil kerja, bukan dikumpulkan di akhir.

## Aturan

1. **Isi sambil kerja.** Catat entri begitu satu pekerjaan selesai, jangan menumpuk di akhir.
2. **Tulis entri sendiri.** Setiap anggota hanya mengisi barisnya sendiri, dari akun GitHub masing-masing. Jangan menulis atas nama anggota lain.
3. **Wajib ada bukti.** Setiap entri harus mencantumkan hash commit atau nomor PR.
4. **Tanggal harus jujur.** Isi tanggal kerja yang sebenarnya, bukan tanggal mengisi log.
5. **Tambah baris di paling bawah.** `git pull` dulu sebelum menambah entri supaya entri anggota lain tidak tertimpa.
